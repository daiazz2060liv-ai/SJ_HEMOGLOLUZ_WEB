HEMOGLOLUZ — WEB EUREKA 2026
================================

Contenido:
- index.html: página web completa.
- assets/: imágenes seleccionadas del informe.
- .nojekyll: permite publicar los archivos estáticos directamente en GitHub Pages.

PUBLICACIÓN EN GITHUB PAGES
1. Crea o abre el repositorio de tu proyecto.
2. Sube index.html y la carpeta assets completa.
3. En Settings > Pages, selecciona "Deploy from a branch".
4. Selecciona la rama principal y la carpeta /(root).
5. Guarda y espera la publicación.

IMPORTANTE:
- No renombres index.html.
- Sube toda la carpeta assets para que funcionen las imágenes.
- La web está diseñada sin dependencias externas, por lo que los gráficos funcionan directamente en GitHub Pages.
- La versión pública omite datos personales de contacto del informe.
